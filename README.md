Windows Dev Studio

Windows Dev Studio is an AI-powered Windows Desktop Development Environment built with C#, .NET 8 and WPF.

Vision

Create a complete desktop development studio for building, editing, managing, testing and debugging software projects.

Planned Features

- AI-powered coding assistant
- Code editor
- Project and file explorer
- Integrated Windows Terminal
- Android development support
- Project build and test tools
- Error detection and debugging
- Secure AI provider configuration
- Windows executable publishing

Technology Stack

- C#
- .NET 8
- Windows Presentation Foundation (WPF)
- Visual Studio 2022
- GitHub

Platform

Windows 10 and Windows 11.

Development Status

Initial development stage.

Features will be implemented and tested step by step.

Security

- Never store API keys or passwords in source code.
- Ask user permission before modifying project files.
- Ask user permission before running potentially destructive commands.
- Keep user projects and data protected.
